# Career Counseling Web Application

## Assignment Category: 004

## live link - https://careerhub-anisul-haque.netlify.app/

## Project Description

This **Career Counseling Web Application** is designed to guide users in exploring career-related services through a modern, responsive, and secure platform. The application provides both online and offline services, with details accessible only to authenticated users. With Firebase integration, users can register, log in, and even update their profiles. Thoughtful animations and responsive design enhance the user experience, ensuring accessibility and visual appeal.

---

## Features

- **Authentication**: Secure user authentication using Firebase (email-password and Google login).
- **Conditional Access**: Service details are visible only to logged-in users, ensuring data privacy and personalized access.
- **Profile Management**: Users can update their profile information easily through the profile section.
- **Responsive UI**: Styled using Tailwind CSS, the application offers a seamless experience across devices.
- **Interactive Animations**: AOS library enhances engagement with smooth scroll-based animations.

---

## Technologies Used

### **Frontend Framework and Libraries**

- **React.js**: Core framework for building the dynamic user interface.
- **React Router**: For routing and navigation between pages, including private routes for secure access.
- **React Private Routes**: To restrict access to specific pages based on the user's authentication status.

### **Styling and Animations**

- **Tailwind CSS**: For crafting a responsive and modern user interface.
- **DaisyUI**: Integrated with Tailwind for pre-designed components, simplifying the styling process.
- **AOS (Animate On Scroll)**: For adding smooth animations triggered by scrolling.
